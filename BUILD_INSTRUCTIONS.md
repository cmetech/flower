# OSCAR Flower wheel

The OSCAR Taskmanager image installs the `oscar-flower` wheel from
`oscar/oscar-taskmanager/wheels/`. The package still imports as `flower`.

## Build and copy

Run from this repository. In the normal sibling checkout layout:

```bash
./build_and_deploy.sh
```

For an isolated Taskmanager worktree, point to its wheels directory:

```bash
TASKMANAGER_WHEELS_DIR=/absolute/path/to/oscar-taskmanager/wheels ./build_and_deploy.sh
```

The script packages the committed static assets and replaces the old
`oscar_flower-*.whl` in that directory. Rebuild the Taskmanager image and
restart Taskmanager and Flower when deploying the new wheel.

## Bootstrap assets

Flower 2.2 uses Bootstrap 5.3.8. Its Bootstrap overrides live in
`scss/flower.scss`; `scss/build.sh` regenerates the committed Bootstrap CSS
and JavaScript when that file changes. The separate `flower/static/css/flower.css`
contains the application styles and is not generated by the wheel script.
